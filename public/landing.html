Everything a mod team needs

Set it up once. ModBot handles the boring parts and keeps a record of everything.

🛡️

Auto-mod

Filters for banned words, spam, mass mentions and unwanted links. Moderators are exempt.

⚠️

Warnings that escalate

Set how many warnings lead to a timeout, and for how long. It happens automatically.

🖥️

A real dashboard

Log in with Yapin’ to warn, time out, ban, edit settings and review activity from your browser.

🔎

Member lookup

See any member’s roles, warnings, private notes and history on one page.

📝

Mod log and notes

Send actions to a log channel and leave private notes for the rest of your team.

⏱️

Always on

The bot restarts itself if it drops, and a Status page shows its health at a glance.

Up and running in three steps

1

Add the bot

Add ModBot to your Yapper server and send a message so it can see the server.

2

Log in

Use Login with Yapin’. Server managers get full control, moderators get warn and timeout tools.

3

Choose your rules

Switch filters on, add banned words, set the escalation steps and a mod-log channel.

Prefer typing? There are commands

Type !help in your server to see what you can use.

Everyone

!help!rules!mywarnings!userinfo!roll!choose a | b

Moderators

!warn!timeout!unwarn!history!note!topwarned!stats

Managers

!ban!unban!addword!filter!escalate!setrules!setlog
